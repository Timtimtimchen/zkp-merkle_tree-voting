# ZK-Voting System：系統架構




## 📍 階段一：選前準備與行政管理 (Admin Setup)
> 目標：設定候選人、建立選民白名單、控制選舉開關。

1. **【前端】(Vue 3 - `Admin.vue`)**
   - **動作**：管理員輸入密碼登入，在畫面上輸入候選人名字或合格學號。
   - **技術**：透過 axios / fetch 送出 HTTP POST 請求。
2. **【後端】(Node.js + MySQL)**
   - **動作**：接收請求，將資料寫入 MySQL 資料庫的 `candidates` (候選人)、`students` (白名單) 與 `settings` (全域設定) 表格中。
   - **備註**：此階段純粹為 Web2 傳統操作，完全沒有接觸區塊鏈。

---

## 📍 階段二：選民註冊與領取憑證 (Registration)
> 目標：確認學生身份，發放密碼，並將身份以「亂碼」形式記錄到區塊鏈。

1. **【前端】(Vue 3 - `Register.vue`)**
   - **動作**：學生輸入自己的學號，按下「領取憑證」。
2. **【前端】(zk.js 工具)**
   - **動作 (產鑰匙)**：利用 `Math.random()` 在瀏覽器背景隨機產生兩組極度機密的數字：`Secret` (證明我是我) 與 `Nullifier` (防止我投第二次)。
   - **動作 (算亂碼)**：利用 `Poseidon Hash` 演算法，將上述兩把鑰匙揉合成一串無法反推的亂碼，稱為 **`Commitment`**。
3. **【前端 ➔ 後端】**
   - **動作**：前端只將「學號」與「`Commitment`」傳給後端。（私鑰永遠留在學生手機畫面）。
4. **【後端】(Node.js + MySQL)**
   - **動作**：比對 MySQL，確認該學號在白名單內且未領過憑證。將 `Commitment` 存入資料庫。
5. **【後端】(Node.js 內部運算)**
   - **動作**：後端撈出資料庫裡所有的 Commitment，重新兩兩相加疊加，**計算出一組全新的 `Merkle Root` (最新版名冊的防偽指紋)**。
6. **【後端 ➔ 智能合約】(ethers.js)**
   - **動作**：後端掏出自己的錢包代付手續費 (Gas)，呼叫智能合約的 `updateRoot(newRoot)`，將最新的指紋永久刻在區塊鏈上。

---

## 📍 階段三：零知識匿名投票 (Anonymous Voting)
> 目標：在完全不暴露身份的情況下，用數學向區塊鏈證明自己擁有投票權。

1. **【前端】(Vue 3 - `Vote.vue`)**
   - **動作**：學生輸入之前拿到的 `Secret`、`Nullifier`，並選擇候選人。
2. **【前端】(zk.js 工具)**
   - **動作 (算樹枝)**：向後端要來目前所有的 `Commitment` 名單，在手機本地端自己算出 `Merkle Root`，並找出自己的亂碼在這棵樹裡的「路徑 (Merkle Path)」。
3. **【前端】(snarkjs 零知識魔法)**
   - **動作 (產證明)**：呼叫 `snarkjs.groth16.fullProve`，將剛才的私鑰與路徑丟入 `.wasm` 電路檔案中運算。
   - **產出結果**：產出一個龐大的數學矩陣 **`Proof`**，以及作廢碼雜湊 **`Nullifier Hash`**。
4. **【前端 ➔ 後端】**
   - **動作**：前端將 `Proof`、`Root`、`Nullifier Hash` 以及要投的 `候選人 ID` 打 API 送給後端。
5. **【後端 ➔ 智能合約】(Node.js Relay)**
   - **動作**：後端此時化身為「無腦中繼器」，完全不審核這張票，只負責代墊手續費，把這包資料丟進智能合約的 `vote(...)` 函數。
6. **【智能合約】(Voting.sol + Verifier.sol)**
   - **動作 (邏輯審查)**：檢查 `Root` 是否跟當初註冊的一樣？檢查 `Nullifier Hash` 是否用過了（防重複投票）？
   - **動作 (數學審查)**：把 `Proof` 丟給 `Verifier.sol` 進行橢圓曲線驗證。
   - **動作 (計票)**：若所有驗證皆通過，合約為該候選人 `votes + 1`，並將該 `Nullifier Hash` 列入已投票黑名單。

---

## 📍 階段四：開票與盲投 (Tallying)
> 目標：動態展示票數，並具備防棄保的盲投機制。

1. **【前端】(Vue 3 - `Results.vue`)**
   - **動作**：進入開票畫面，不斷向後端發送拉取票數的請求。
2. **【後端 ➔ 智能合約】(ethers.js)**
   - **動作**：後端對智能合約發出免費的 `View` 請求，直接讀取區塊鏈上各候選人的真實票數。
3. **【後端內部攔截】(Node.js + MySQL)**
   - **動作**：後端檢查 MySQL 中的 `settings`。如果管理員開啟了「盲投 (隱藏票數)」，後端會強制把從區塊鏈讀到的真實票數全部覆寫為 `0`。
4. **【後端 ➔ 前端】**
   - **動作**：將最終決定好的數字回傳給前端。
5. **【前端】(Vue 3 + CSS)**
   - **動作**：若數字為 0 (盲投)，顯示鎖定畫面；若有數字，利用 Vue 的響應式綁定與 CSS 轉場動畫，流暢地長出得票長條圖。
